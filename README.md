# Thedracode — dépôt historique

Ce dépôt correspond à un ancien import partiel des ressources du projet **Dracode**. Il ne contient pas une application autonome et n'est plus utilisé comme source de développement.

## Projet actif

Le projet maintenu, corrigé et documenté est disponible ici :

- [Dracode](https://github.com/adambbk/Dracode)

Dracode présente un site vitrine responsive de création de sites web, avec navigation, offres de services et parcours de commande.

## Pourquoi ce dépôt est conservé

Il est conservé uniquement pour préserver l'historique du travail. Les ressources dupliquées ont été retirées afin d'éviter de présenter deux versions concurrentes du même projet.
